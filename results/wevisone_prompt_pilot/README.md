# WeVisOne-VL-4B 的 BUSI 提示詞初篩

固定 seed 42 的 LoRA + 原生 pixel decoder 微調 checkpoint，在清理後的 BUSI 驗證集比較五種提示。初篩涵蓋驗證集全部 13 張正常影像，以及依既有資料順序各取 4 張良性和 4 張惡性影像。所有提示使用相同影像、CPU float32 和 greedy decoding，每張影像把五種提示放在同一批次生成，最多生成 128 tokens，repetition penalty 為 1.0。這輪未使用額外的病灶存在門檻。

| 提示 | 正常影像誤報 | 病灶 Dice | 病灶影像空遮罩 |
|---|---:|---:|---:|
| 原提示 breast lesion | 1/13 | 0.9300 | 0/8 |
| 原提示 + 無可見病灶就回傳 None | 0/13 | 0.9299 | 0/8 |
| 描述為超音波上可見的局部病灶 | 0/13 | 0.9293 | 0/8 |
| 原提示 + 排除正常組織、聲影和偽影 | 1/13 | 0.9282 | 0/8 |
| 改用 breast mass | 2/13 | 0.9289 | 0/8 |

加上 `If no breast lesion is visible, return None.` 後，`normal (22).png` 從輸出病灶框與 603 個前景像素，改為輸出 `None` 和空遮罩。8 張病灶影像的平均 Dice 只下降約 0.0001。

每張影像若有多個實例，先對各遮罩的機率逐像素取最大值，再雙線性縮放至 256×256，以 >0.5 轉成二值遮罩。正常影像只要有任一前景像素就計為誤報。病灶 Dice 為 8 張有病灶影像的逐張平均。

改善來自 1 張驗證影像。先前 GPU 原提示紀錄在這 13 張正常影像上有 2 張誤報，本輪 CPU 原提示有 1 張。表內比較採用同一次 CPU 初篩的原提示結果。完整驗證集、BUSI 測試集與 BUS-UCLM 尚未用這組提示比較。
