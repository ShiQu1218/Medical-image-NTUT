# 等樣本數資料品質比較：訓練參數

本輪主要比較改為「按類別抽樣的原版」對「清理版」。保留第一輪切分；只從原版訓練分區抽樣，不重新切分驗證或測試資料。

| 項目 | 固定設定 |
|---|---|
| 兩組訓練數 | 各 368 張：良性 207、惡性 112、正常 49 |
| 共用驗證集 | 85 張乾淨影像 |
| 共用測試分區 | 76 張乾淨影像；本輪完全不載入或評估 |
| 原版抽樣 | NumPy default_rng(2026)，按類別不放回抽樣；清單 sampled_original.csv |
| 模型 | U-Net，channels 16/32/64/128/256；1,940,817 個參數；從零訓練，無 BatchNorm／Dropout |
| 影像 | 灰階 256×256，前處理後除以 255；遮罩合併後最近鄰縮放 |
| 最佳化器 | Adam：lr=0.001、betas=(0.9,0.999)、eps=1e-8、weight_decay=0 |
| 損失 | BCEWithLogitsLoss + (1 − 每張 soft Dice 的平均)，兩項權重各 1，Dice smoothing=1 |
| 批次 | 16；每 epoch 23 次更新，末批次保留 |
| 更新預算 | 每組 2,800 次；另保存 1,400 次內的最佳模型；兩組均約 60.87／121.74 epochs |
| 驗證頻率 | 每 35 次更新，閾值 0.5，選最佳驗證 Dice；無學習率排程與早停 |
| 種子 | 訓練 42／43／44；每個方法與資料組同種子初始化相同 |
| 資料增強 | 僅訓練：旋轉 ±10°、縮放參數 0.95–1.05、零填補；影像雙線性、遮罩最近鄰，同步變換 |
| 方法 | 原圖；CLAHE clip=2、grid=8×8；SRAD iterations=20、step=0.5、全圖 q0；3×3 中值；CLAHE→SRAD |
| 執行 | RTX 5080，FP32、channels_last、決定性演算法；套件沿用第一輪 |

兩組皆可視為 529 張的完整比較分區：訓練 368＋驗證 85＋測試 76，但本輪只使用訓練與驗證。
抽樣組訓練影像中有 251 張也在清理版訓練集，兩組不是獨立資料來源；原清理規則會排除其餘 117 張。
抽樣保留原資料中的重複／異常可能性，不先去重再抽樣；已知重複群組仍不跨訓練與驗證分區。

本輪只有一份固定抽樣清單，三個訓練種子的 SD 不包含抽樣清單變異。兩個更新預算來自同一條訓練軌跡。
清理版原圖三個種子的六份已完成快照沿用前一輪等更新實驗；輸入、模型、訓練演算法與驗證頻率相同，metrics.json 記錄 reused_from 及來源 config。其餘組別重新執行。
